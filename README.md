# Дашборд мастермайнда — инструкция по запуску

Это обычный статический сайт (HTML/CSS/JS), никакой установки не требуется.
Прогресс каждого участника сохраняется прямо в браузере (localStorage),
поэтому запускайте сайт **из одной и той же папки в одном и том же браузере**,
чтобы отметки не терялись.

## Способ 1 — просто открыть файл (самый простой)

Дважды кликните на `index.html` — сайт откроется в браузере по умолчанию.
Обычно этого достаточно.

## Способ 2 — через локальный сервер (рекомендуется)

Иногда браузеры ограничивают работу localStorage при открытии файлов напрямую
(`file://`). Если прогресс не сохраняется — запустите локальный сервер:

**Если установлен Python 3:**
```bash
cd путь/до/папки/site
python3 -m http.server 8000
```
Затем откройте в браузере: http://localhost:8000

**Если установлен Node.js:**
```bash
cd путь/до/папки/site
npx serve .
```
и откройте ссылку, которую покажет команда (обычно http://localhost:3000).

## Структура файлов

```
site/
├── index.html          — дашборд (общая статистика + карточки участников)
├── participant.html    — страница задач конкретного участника
├── css/style.css        — стили
├── js/data.js           — список участников и задач (можно редактировать)
└── js/app.js             — логика приложения
```

## Как редактировать список задач

Откройте `js/data.js` — там простой список объектов. Для каждой задачи:
- `qty` — сколько единиц нужно выполнить (например, 5 экскурсий → `qty: 5`).
  Обычная задача без счётчика → `qty: 1`.
- `deadline` — дата в формате `'YYYY-MM-DD'` или `null`, если срока нет.
- `note` — необязательный комментарий-пояснение.

## Индикация дедлайнов

- 🔴 Красный — срок прошёл, задача не выполнена.
- 🟡 Жёлтый — осталось 5 дней или меньше.
- Обычный — срок ещё не горит.
- ✅ Зелёный — задача выполнена (даже частично закрытые многосоставные
  задачи, например 3 из 5 экскурсий, засчитываются пропорционально в процент
  выполнения, а полностью закрытые подсвечиваются зелёным).

## Как отмечать выполнение

- **Обычная задача** — нажмите на чекбокс или на текст задачи.
- **Составная задача** (например, «5 экскурсий») — используйте кнопки **+ / −**
  под задачей, чтобы прибавлять по одной. Каждая единица сразу добавляет
  свою долю в процент выполнения (1/5 = 20% и т.д.). Клик по тексту задачи
  сразу отмечает её как полностью выполненную (повторный клик — сбрасывает).

Прогресс хранится локально в вашем браузере и не отправляется никуда в сеть.

## Баллы и рейтинг

- **2 балла** — за каждую полностью выполненную задачу (не важно, простая она
  или составная — засчитывается сам факт закрытия задачи).
- **3 балла** — за каждого вовлечённого человека (см. ниже).
- На дашборде участники автоматически сортируются по количеству баллов:
  топ-3 показаны на «подиуме» с медалями 🥇🥈🥉, остальные — ниже, с номером
  места.

## Вовлечение

Отдельная метрика на странице участника (не входит в список задач).
У каждого участника есть **минимальная планка** (её нужно достичь), но
максимума нет — вовлекать можно сколько угодно людей сверх нормы:

- Ирина, Игорь, Виктория, Нурсултан, Тагир — планка **1**
- Евгений — планка **5**

Планку легко изменить в `js/data.js` — поле `engagementMin` у каждого
участника. Баллы за вовлечение и его сумма по всей группе показаны на
дашборде отдельным блоком с собственным кольцом прогресса.
